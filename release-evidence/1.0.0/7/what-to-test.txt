Build 7 — packages as packages, 500-line source ceiling, complete OSS notices

Open a project that has a dependency (or add github.com/google/uuid). The left sidebar should show a Packages section with the module name, not vendor/github.com/… and every file inside it. Add package searches and installs. Swipe to remove. From Projects, Add packages is in the all-projects list and can target any project.

On iPhone, open Terminal, then pick a file in Files: the editor (Code) must come forward.

Settings → Acknowledgements must name Go, WasmKit, ZIPFoundation, swift-system, and WasmKit’s SwiftPM graph (swift-nio, collections, atomics, log, argument-parser) plus go-cmp.

A GitHub or Files import should drop a source file longer than 500 lines rather than open it. Installing a module whose .go files exceed 500 lines should refuse with that reason.

Known limitations from build 6 remain: Stop does not yet guarantee a CPU-loop halt within one second. Do not test runaway code.
