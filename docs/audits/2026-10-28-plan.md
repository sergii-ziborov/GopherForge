## Reporting and release rules

Each package records actual tests, source/build identity, remaining device/provider conditions and migration/rollback. A passing build does not establish semantic refactoring or race freedom. Earlier failed test runs remain available. User files and unrelated simulators are preserved. Never call a proposed feature released because its source exists.
