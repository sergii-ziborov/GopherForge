# Learning expansion in 1.1.2

Private Internal QA TestFlight build **1.1.2 (35)** adds 26 reading lessons with 78 authored
sections and worked code walkthroughs. There are now 73 teaching lessons in
13 units, alongside the original 22 prediction challenges. The 69 existing
visual guides and compiler-judged exercises remain intact.

Reading completion is self-reported and persisted; it never invokes the
compiler or claims a compiler pass. Go examples have the existing syntax
highlighting and full-screen reader. Shell, container and deployment examples
are explanatory material for the learner's own development environment, not
new iOS execution capabilities.

## Content

- **Core:** scope and shadowing; following result/error paths.
- **Collections:** slice headers and backing arrays; concurrent append and
  ownership; large buffers retained by small slices.
- **Concurrency:** bounded workers and admission control; cancellation and
  joining owned goroutines.
- **Runtime and memory:** stack/heap lifetimes, escape analysis, GC reachability,
  allocation and memory budgets, goroutines/threads/GOMAXPROCS, diagnostic profiles.
- **Go services:** HTTP request lifecycles, Gin routes and validation, Redis
  connection pools and capacity, cache stampedes and retry amplification.
- **Architecture and clean code:** cohesive packages, consumer interfaces,
  ports/adapters, modular monolith and microservice tradeoffs, explicit errors.
- **Around Go:** Bash quoting and pipelines; Docker build/runtime stages;
  Podman networking/rootless behavior; Kubernetes workloads, resources,
  readiness/liveness and graceful shutdown.

References are linked in each lesson to the relevant Go, Gin, Redis, GNU,
Docker, Podman or Kubernetes documentation. Example values are illustrative;
the material does not prescribe universal deployment budgets.

## Review and workspace

Review has an explicit **Finish review** action after the final completed
round. Boards contain 3–5 learned pairs, and sessions contain 3–5 rounds.
Small learned pools use labelled reinforcement; unfinished concepts are never
used to fill a board. Early learning with fewer than three available pairs
explains that more learned material is needed. Knowledge and mistake questions
retain exactly three choices. Restart resets completion controls.

Conventional iPhone landscape section controls keep their display position
when the software keyboard appears. The keyboard may cover them while the
editor continues to avoid the keys and its accessory. Established Duo laptop
and portrait workspace layouts are unchanged.

This work is for TestFlight only. No new App Review submission is authorized.
The 1.1.1 (33) distribution is left untouched.

completion and persistence without a compiler, navigation to the deployment
unit, three Review rounds with restart and Finish, matching tile visibility,
saved mistake corrections and the iPhone landscape keyboard overlay. All 26 Go

reading example and Finish action. No new Duo hardware validation is claimed.
