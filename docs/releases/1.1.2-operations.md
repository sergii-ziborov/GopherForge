# Around Go expansion — 1.1.2 (36)

Around Go now contains 25 practical reading lessons in three units, up from six:

| Unit | Lessons | Workflows |
| --- | ---: | --- |
| Command line | 11 | Files, text search/logs, quoting, pipelines, process signals, scripts/environment, Git, Go tools, curl, systemd |
| Containers | 6 | Dockerfile, build/run/inspect/stop, Compose, storage, Podman, registries/platforms |
| Kubernetes | 8 | Context/namespace, workloads, dry-run/diff/apply, Pod diagnostics, Service routing, config, probes/shutdown, rollout/scale/undo |

The complete course has **92 teaching lessons in 15 units**, with 22 separate
prediction challenges. There are 45 reading lessons with 135 authored sections;
the 69 original visual guides remain bundled. Previously completed reading IDs
are preserved when moving container and Kubernetes material into their own units.

Shell, YAML and Dockerfile examples share language-aware highlighting in the
lesson, full-screen reader and corresponding project files. The full-screen
reader starts at the top. Readings participate in concept matching and the
three-choice mistake question bank; completion remains self-reported and never
claims a compiler pass. Command examples run in the learner's development
environment, not as new execution capabilities in the iOS sandbox.
