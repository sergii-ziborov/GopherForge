# GopherForge 1.1.5 — build 43

Build 43 replaces build 42 in the pending 1.1.5 submission. The native application
and learning resources retain build 42 behavior; only the app and Share extension
build numbers increase. The product README, screenshot capture driver and listing
images are refreshed. The public App Store version was 1.1.4 (39) when this release
was prepared on 21 October 2026.

## Verification

- Release IPA validated and uploaded without errors; app and extension are 1.1.5 (43).
- Minimum iOS 18; iPhone and iPad device families retained.
- Six behavioral checks passed: interview resume and self-assessment after relaunch,
  course Continue after a completed reading, bookmark persistence, completion and
  compiler evidence after history trimming, and root/detail navigation.
- One earlier root-navigation run did not reach Settings. The complete flow passed
  unchanged on its repeat; the final accepted run had no failures or skipped tests.
- The release archive's reading and interview resources match the repository byte
  for byte: 88 interview guides, including eight on Go with coding agents.
- Twelve Course/Interview frames across six sets are captured from native app surfaces, with their build, source hash,
  dimensions and image hashes recorded in `1.1.5-screenshots.json`.
- Duo learning frames use the native outer display (1398 × 2034), an accepted
  Apple screenshot specification. Three existing open-display feature images remain.
- The capture driver launches Course and Interview separately, verifies the selected
  area and expected controls, then captures the app. This avoids stale tab state and
  unreliable transition-time taps; it makes no changes to the shipped application.

The exact final Apple state, selected build and automatic release setting are in
`1.1.5-submission.json`. The replaced build's submission is preserved in
`1.1.5-build42-submission.json`. Asset delivery and creative placement verification
are in `1.1.5-assets-verified.json`.
