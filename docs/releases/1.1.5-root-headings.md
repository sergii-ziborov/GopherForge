# 1.1.5 (42): cleaner tab roots

Removed the large, repeated Projects, Learn and Settings root navigation headings. Their selected tabs already name the section. Content now uses the reclaimed vertical space, with the existing spacing inside each screen retained.

The Build workspace keeps its project title. Pushed lessons, interview guides, Project library and Third-Party Library keep their own titles and Back controls. No progress keys, course data or project data changed.
